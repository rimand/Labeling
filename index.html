Die-cut spacing guide

Gap ≥ 3 mm between labels so the blade and waste strip have room. Use 0 only for straight guillotine cuts.

Safe zone 1.5–2 mm: keep text and codes inside the blue dotted line, die-cut drifts ±0.5–1 mm.

Bleed 1–2 mm with a background colour so no white edge shows (gap must be ≥ 2× bleed).

Corner radius 1–3 mm peels better and matches most standard dies.

Send the shop the PDF (cut line on Screen) + the die-line SVG (red stroke, same sheet size).

Silhouette Cameo 4 workflow
  1. Reg marks = Silhouette Type 1; length, thickness and inset the same as in Studio.
  2. Clear any "overlaps reg marks" warning (raise the margin).
  3. Cut line = Screen → Print at 100% / Actual size.
  4. Die-line → DXF file.
  5. Studio: Page Setup → same paper size & orientation; Registration Marks → Type 1, same values.
  6. Open the DXF → Select all → Group → Transform: X = left margin, Y = top margin.
  7. Load the printed sheet → Send → Cut. The Cameo 4 scans the marks itself.
Matte paper reads best; glossy or laminated sheets can fail the scan. Keep ink out of the mark areas.
When printing, set Scale to 100% / Actual size and turn off headers & footers.
